# Hello Hugo

A simple "Hello World" Hugo static site.

## Prerequisites

- [Hugo](https://gohugo.io/installation/) installed on your system

## Running Locally

To run the site locally:

```bash
hugo server
```

This will start a development server at `http://localhost:1313`.

## Building

To build the static site:

```bash
hugo
```

The output will be in the `public/` directory.

## Adding More Posts

Create new posts in the `content/posts/` directory with the following format:

```markdown
---
title: "Post Title"
date: 2024-01-01T00:00:00Z
draft: false
---

Your post content here...
```
